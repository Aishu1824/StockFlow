# StockFlow

Scalable Order & Inventory Management Platform.

## Overview

StockFlow is a production-oriented order and inventory
management platform designed to explore scalable backend
engineering, concurrency control, asynchronous processing,
caching, observability, and cloud deployment.

## Current Features

- FastAPI backend
- Health check endpoint

## Planned Features

- User authentication
- Product management
- Inventory management
- Order management
- Concurrency-safe inventory reservation
- Redis caching
- Asynchronous order processing
- Observability
- Automated testing
- Docker
- CI/CD
- AWS deployment
